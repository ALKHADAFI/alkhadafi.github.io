1. Tipe Data

Setiap nilai di Python memiliki tipe. Tipe dapat dicek dengan type().

Tipe Nama Contoh Keterangan
int bilangan bulat 25, -7 tanpa pecahan
float bilangan desimal 3.14, -0.5 memakai titik, bukan koma
str teks (string) "Python", 'Halo' diapit tanda kutip
bool logika True, False hanya dua nilai
NoneType kosong None berarti "tidak ada nilai" 
umur = 16            # int
tinggi = 165.5       # float
nama = "Rani"        # str
lulus = True         # bool

print(type(umur))    # <class 'int'>

Konversi tipe

int("25")      # 25
float("3.14")  # 3.14
str(100)       # "100"

Catatan: fungsi input() selalu menghasilkan str, jadi ubah dulu dengan int() atau float() bila ingin menghitung.

umur = int(input("Umur: "))

2. List

List adalah kumpulan data berurutan yang dapat diubah (mutable). Ditulis dengan tanda kurung siku [ ].

buah = ["apel", "jeruk", "mangga"]

Indeks dimulai dari 0; indeks negatif menghitung dari belakang.

buah[0]     # "apel"
buah[-1]    # "mangga"
buah[0:2]   # ["apel", "jeruk"]  (slicing: indeks 0 sampai 1)

Metode yang sering dipakai

Perintah Fungsi
buah.append("pisang") menambah di akhir
buah.insert(1, "anggur") menyisipkan di indeks tertentu
buah.remove("jeruk") menghapus berdasarkan nilai
buah.pop() menghapus dan mengambil elemen terakhir
buah.sort() mengurutkan
len(buah) jumlah elemen
"apel" in buah cek keanggotaan (True/False) 
buah[1] = "melon"   # mengubah elemen (boleh, karena list mutable)

3. Tuple

Tuple mirip list, tetapi tidak dapat diubah (immutable). Ditulis dengan tanda kurung biasa ( ).

titik = (3, 5)
hari = ("Senin", "Selasa", "Rabu")

print(titik[0])      # 3
# titik[0] = 10      # ERROR: tuple tidak bisa diubah

Unpacking (memecah isi tuple ke beberapa variabel):

x, y = titik
print(x, y)          # 3 5

Gunakan tuple untuk data yang tidak boleh berubah, misalnya koordinat atau nama hari.

4. Dictionary

Dictionary menyimpan data berpasangan kunci : nilai (key : value). Ditulis dengan kurung kurawal { }. Kunci harus unik.

siswa = {"nama": "Rani", "kelas": "X", "nilai": 88}
Perintah Fungsi
siswa["nama"] mengambil nilai berdasarkan kunci
siswa.get("hobi", "-") mengambil nilai; jika kunci tidak ada, beri nilai cadangan
siswa["nilai"] = 92 mengubah nilai
siswa["hobi"] = "membaca" menambah pasangan baru
del siswa["kelas"] menghapus pasangan
siswa.keys() semua kunci
siswa.values() semua nilai
siswa.items() semua pasangan (kunci, nilai)
"nama" in siswa cek apakah kunci ada

Menelusuri dictionary

for kunci, nilai in siswa.items():
    print(kunci, ":", nilai)

5. Operator Aritmatika

Operator Nama Contoh Hasil
+ penjumlahan 17 + 5 22
- pengurangan 17 - 5 12
* perkalian 17 * 5 85
/ pembagian (hasil float) 17 / 5 3.4
// pembagian bulat 17 // 5 3
% sisa bagi (modulus) 17 % 5 2
** pangkat 2 ** 5 32

Urutan pengerjaan: tanda kurung ( ) → pangkat ** → *, /, //, % → +, -.

print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20

Operator penugasan: x += 5 sama dengan x = x + 5 (berlaku juga untuk -=, *=, /=).

Operator perbandingan (hasilnya True/False): ==, !=, <, >, <=, >=.

Operator logika: and (keduanya benar), or (salah satu benar), not (kebalikan).

Contoh penggunaan %: bilangan genap jika n % 2 == 0.

6. Perulangan (Looping)

Perulangan while

Berulang selama kondisi bernilai True. Jangan lupa mengubah variabel kondisi agar tidak berulang tanpa henti.

angka = 1
while angka <= 5:
    print("Angka ke-", angka)
    angka += 1

Perulangan for

Berulang untuk setiap elemen dalam sebuah urutan (list, tuple, string, range).

for b in ["apel", "jeruk", "mangga"]:
    print(b)

Fungsi range()

Bentuk Menghasilkan
range(5) 0, 1, 2, 3, 4
range(1, 6) 1, 2, 3, 4, 5
range(2, 11, 2) 2, 4, 6, 8, 10 (loncat 2) 
total = 0
for i in range(1, 6):
    total += i
print(total)         # 15

break dan continue

  • break menghentikan perulangan sepenuhnya.
  • continue melewati sisa isi perulangan dan lanjut ke putaran berikutnya.

Perulangan bersarang (nested loop)

for baris in range(1, 4):
    for kolom in range(1, 4):
        print(baris * kolom, end=" ")
    print()

7. Percabangan (if–elif–else)

Program memilih blok kode berdasarkan kondisi. Indentasi (menjorok 4 spasi) wajib.

nilai = int(input("Masukkan nilai: "))

if nilai >= 85:
    print("Predikat A")
elif nilai >= 70:
    print("Predikat B")
elif nilai >= 55:
    print("Predikat C")
else:
    print("Predikat D")

Aturan penting

  • Kondisi diperiksa dari atas ke bawah; blok pertama yang benar dijalankan, sisanya dilewati.
  • elif dan else bersifat opsional; else tidak memiliki kondisi.
  • Setelah kondisi diakhiri tanda titik dua :.
  • Kondisi dapat digabung: if umur >= 17 and punya_ktp:.

Contoh genap atau ganjil

n = int(input("Bilangan: "))
if n % 2 == 0:
    print("Genap")
else:
    print("Ganjil")

8. Membuat Fungsi

Fungsi adalah blok kode bernama yang dapat dipakai berulang kali. Dibuat dengan def.

def luas_persegi_panjang(p, l):
    return p * l

hasil = luas_persegi_panjang(8, 5)
print("Luas =", hasil)     # Luas = 40

Istilah penting

Istilah Arti
parameter variabel di dalam kurung saat fungsi dibuat (p, l)
argumen nilai yang dikirim saat fungsi dipanggil (8, 5)
return mengembalikan hasil dan mengakhiri fungsi

Fungsi tanpa return hanya menjalankan perintah (misalnya mencetak):

def sapa(nama):
    print("Halo,", nama)

sapa("Rani")

Parameter dengan nilai bawaan (default)

def pangkat(a, n=2):
    return a ** n

pangkat(5)       # 25
pangkat(2, 5)    # 32

Mengembalikan beberapa nilai (dikembalikan sebagai tuple):

def min_maks(data):
    return min(data), max(data)

kecil, besar = min_maks([4, 9, 2, 7])

Ruang lingkup variabel: variabel yang dibuat di dalam fungsi hanya berlaku di dalam fungsi itu (lokal).

Perbandingan List, Tuple, dan Dictionary

Ciri List Tuple Dictionary
Tanda [ ] ( ) { }
Berurutan ya ya ya (berdasarkan urutan masuk)
Dapat diubah ya tidak ya
Akses data dengan indeks dengan indeks dengan kunci
Cocok untuk daftar yang berubah data tetap data berpasangan

Contoh Gabungan: Pengelola Nilai Siswa

def predikat(nilai):
    if nilai >= 85:
        return "A"
    elif nilai >= 70:
        return "B"
    elif nilai >= 55:
        return "C"
    else:
        return "D"

def rata_rata(data):
    return sum(data.values()) / len(data)

nilai_siswa = {}
jumlah = int(input("Jumlah siswa: "))

i = 1
while i <= jumlah:
    nama = input("Nama: ")
    nilai_siswa[nama] = int(input("Nilai: "))
    i += 1

for nama, nilai in nilai_siswa.items():
    print(nama, ":", nilai, "(" + predikat(nilai) + ")")

print("Rata-rata kelas =", rata_rata(nilai_siswa))

Pesan error Penyebab umum

SyntaxError lupa tanda : atau tanda kutip/kurung tidak berpasangan
NameError memakai variabel atau fungsi yang belum dibuat
TypeError operasi antartipe tidak cocok, misalnya "5" + 3
IndexError indeks list melebihi jumlah elemen
KeyError kunci tidak ada di dictionary (gunakan .get())
