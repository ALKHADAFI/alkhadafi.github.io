Materi: Struktur Data Abstrak Menggunakan struct di C++

Materi ini membantu kamu mengerjakan Lembar Kerja Siswa: Struktur Data Abstrak Menggunakan struct. Bacalah dari awal sampai akhir, lalu kerjakan lembar kerjanya. Contoh program di sini sengaja dibuat berbeda dari soal, supaya kamu belajar caranya, bukan menghafal jawabannya.

1. Mengapa Kita Butuh struct?

Bayangkan kita ingin menyimpan data satu siswa: nama dan nilai. Dengan variabel biasa, kodenya seperti ini:

string nama1 = "Ani";
int nilai1 = 80;

string nama2 = "Budi";
int nilai2 = 75;

Untuk 2 siswa saja sudah ada 4 variabel yang terpisah. Bagaimana kalau ada 30 siswa? Akan ada 60 variabel, dan kita mudah salah mencocokkan nama7 dengan nilai7.

Masalahnya: nama dan nilai milik satu siswa seharusnya disimpan bersama, seperti satu kartu data siswa yang berisi beberapa kolom.

C++ menyediakan struct untuk keperluan ini.

struct adalah cara membuat tipe data baru dengan menggabungkan beberapa data (yang boleh berbeda tipe) ke dalam satu kesatuan.

2. Apa Itu Struktur Data Abstrak (ADT)?

ADT adalah singkatan dari Abstract Data Type, atau Tipe Data Abstrak.

Kata "abstrak" artinya kita fokus pada apa yang disimpan dan apa yang bisa dilakukan, bukan pada bagaimana komputer menyimpannya di memori.

Contoh dari kehidupan sehari-hari: remote TV.

  • Remote punya tombol (volume, ganti saluran, nyala/mati). Itu adalah operasi yang bisa kita lakukan.
  • Kita tidak perlu tahu rangkaian elektronik di dalamnya. Kita cukup tahu cara memakainya.

Sebuah ADT selalu terdiri dari dua bagian:

Bagian Artinya Di C++ ditulis dengan
Data (representasi) Apa saja yang disimpan struct
Operasi Apa saja yang dapat dilakukan pada data itu fungsi atau prosedur

Contoh ADT Waktu:

  • Data: jam dan menit
  • Operasi: menambah menit, menampilkan waktu, membandingkan dua waktu

3. Cara Membuat struct

Bentuk umumnya:

struct NamaTipe {
    tipe1 anggota1;
    tipe2 anggota2;
    // ... dan seterusnya
};

Contoh: ADT untuk waktu.

struct Waktu {
    int jam;
    int menit;
};

Mari bedah satu per satu:

Bagian Penjelasan
struct Kata kunci untuk membuat tipe data baru
Waktu Nama tipe baru yang kita buat (bebas, awali dengan huruf besar agar mudah dibedakan)
jam, menit Anggota (field): data yang dimiliki oleh Waktu
; setelah } Wajib ada. Lupa titik koma ini adalah kesalahan yang sangat sering terjadi

Penting dipahami: menulis struct Waktu { ... }; belum membuat variabel apa pun. Kita baru membuat "cetakan" atau rancangan tipe data. Ibarat denah rumah: denah sudah ada, tetapi rumahnya belum dibangun.

4. Membuat Variabel dan Mengakses Anggotanya

Setelah tipe dibuat, kita bisa membuat variabel dari tipe itu, sama seperti membuat variabel int.

Waktu w1;        // membuat variabel w1 bertipe Waktu

Untuk mengisi atau membaca anggota, gunakan operator titik (.):

w1.jam = 7;
w1.menit = 30;

cout << w1.jam << ":" << w1.menit;   // mencetak 7:30

Cara membacanya: w1.jam artinya "anggota jam milik variabel w1".

Satu struct dapat dipakai untuk membuat banyak variabel, dan masing-masing punya data sendiri:

Waktu berangkat, pulang;

berangkat.jam = 6;
berangkat.menit = 45;

pulang.jam = 14;
pulang.menit = 10;

Variabel berangkat dan pulang adalah dua "kartu" yang berbeda. Mengubah isi yang satu tidak memengaruhi yang lain.

Kesalahan yang sering terjadi

Salah Benar Alasan
Waktu.jam = 7; w1.jam = 7; Titik dipakai pada variabel, bukan pada nama tipe
w1 = 7; w1.jam = 7; Variabel struct berisi beberapa data, jadi harus menyebut anggota yang diisi
struct Waktu { int jam; int menit; } struct Waktu { int jam; int menit; }; Titik koma setelah } tidak boleh lupa

5. Memberi Nilai Awal (Inisialisasi)

Selain mengisi anggota satu per satu, kita bisa mengisi semuanya sekaligus saat variabel dibuat, memakai tanda kurung kurawal:

Waktu w2 = {9, 15};    // jam = 9, menit = 15

Nilai di dalam { } diisikan sesuai urutan anggota pada struct. Karena jam ditulis lebih dulu daripada menit, maka 9 masuk ke jam dan 15 masuk ke menit.

Contoh dengan beberapa tipe data berbeda:

struct Siswa {
    string nama;
    int nilai;
};

Siswa s1 = {"Ani", 80};

6. Menyalin Variabel struct

Perhatikan program berikut:

#include <iostream>
#include <string>
using namespace std;

struct Siswa {
    string nama;
    int nilai;
};

int main() {
    Siswa p;
    p.nama = "Citra";
    p.nilai = 70;

    Siswa q = p;      // menyalin isi p ke q
    q.nilai = 95;     // mengubah q saja

    cout << p.nilai << " " << q.nilai;
    return 0;
}

Keluarannya adalah 70 95.

Penjelasan langkah demi langkah:

  1. p berisi nama "Citra" dan nilai 70.
  2. Siswa q = p; membuat variabel baru q dan menyalin seluruh isi p ke dalamnya. Sekarang q juga berisi "Citra" dan 70.
  3. q.nilai = 95; hanya mengubah nilai milik q.
  4. Variabel p tidak ikut berubah, karena p dan q adalah dua tempat penyimpanan yang terpisah. Yang terjadi pada langkah 2 adalah fotokopi, bukan "satu data dengan dua nama".

Gambaran di memori setelah langkah 3:

  p                   q
+---------------+   +---------------+
| nama : Citra  |   | nama : Citra  |
| nilai: 70     |   | nilai: 95     |
+---------------+   +---------------+

Ingat prinsip ini: menyalin struct membuat salinan yang berdiri sendiri.

7. struct sebagai Parameter Fungsi

Sebuah struct dapat dikirim ke fungsi sama seperti int atau string. Ini membuat daftar parameter menjadi ringkas. Bandingkan:

// Tanpa struct: parameter banyak dan mudah tertukar
void cetakWaktu(int jam, int menit);

// Dengan struct: cukup satu parameter
void cetakWaktu(Waktu w);

Contoh lengkap:

#include <iostream>
using namespace std;

struct Waktu {
    int jam;
    int menit;
};

void cetakWaktu(Waktu w) {
    cout << w.jam << " jam " << w.menit << " menit" << endl;
}

int main() {
    Waktu w1 = {2, 40};
    cetakWaktu(w1);        // mencetak: 2 jam 40 menit
    return 0;
}

Parameter menerima salinan

Cara pengiriman di atas disebut pass by value. Fungsi menerima salinan dari struct, sama seperti pada Bagian 6. Akibatnya, mengubah struct di dalam fungsi tidak mengubah variabel aslinya.

void tambahSatuJam(Waktu w) {
    w.jam = w.jam + 1;      // hanya mengubah salinan
}

int main() {
    Waktu w1 = {2, 40};
    tambahSatuJam(w1);
    cout << w1.jam;         // tetap 2, bukan 3
    return 0;
}

Lalu bagaimana kalau kita ingin hasilnya sampai ke luar fungsi? Jawabannya ada di bagian berikut.

8. struct sebagai Nilai Kembalian Fungsi

Fungsi juga boleh mengembalikan sebuah struct. Dengan begitu, hasil perhitungan yang terdiri dari beberapa data bisa dikirim sekaligus.

Contoh: fungsi yang menambah sejumlah menit pada sebuah waktu.

Waktu tambahMenit(Waktu w, int m) {
    Waktu hasil;
    int total = w.jam * 60 + w.menit + m;   // ubah semuanya ke menit
    hasil.jam   = total / 60;
    hasil.menit = total % 60;
    return hasil;                            // kembalikan satu Waktu utuh
}

int main() {
    Waktu a = {1, 50};
    Waktu b = tambahMenit(a, 25);
    cout << b.jam << ":" << b.menit;         // mencetak 2:15
    return 0;
}

Penelusuran untuk tambahMenit({1, 50}, 25):

total=1×60+50+25=135 menit

jam=135÷60=2 (hasil bagi),menit=135mod60=15 (sisa bagi)

Jadi hasilnya adalah 2:15.

Perhatikan pola penulisan fungsi yang mengembalikan struct. Pola ini akan kamu pakai pada lembar kerja:

NamaTipe namaFungsi(NamaTipe parameter, ...) {
    NamaTipe hasil;                 // 1. siapkan wadah untuk hasil
    hasil.anggota1 = ...;           // 2. isi setiap anggota
    hasil.anggota2 = ...;
    return hasil;                   // 3. kembalikan wadahnya
}

Variabel a pada contoh di atas tidak berubah. Fungsi bekerja pada salinan, lalu mengirim hasil baru lewat return.

9. Merancang ADT: Data + Operasi

Sekarang kita gabungkan semuanya. Merancang ADT berarti menjawab dua pertanyaan:

  1. Data apa yang perlu disimpan? Jawabannya menjadi anggota struct.
  2. Apa saja yang ingin kita lakukan pada data itu? Jawabannya menjadi fungsi atau prosedur.

Contoh: ADT Waktu.

// ===== DATA =====
struct Waktu {
    int jam;
    int menit;
};

// ===== OPERASI =====
void cetakWaktu(Waktu w);               // menampilkan waktu
Waktu tambahMenit(Waktu w, int m);      // menambah menit, hasilnya Waktu baru
int   totalMenit(Waktu w);              // mengubah waktu menjadi menit

Tabel operasinya:

Nama operasi Parameter Tipe kembalian Tugas
cetakWaktu Waktu w void Menampilkan waktu ke layar
tambahMenit Waktu w, int m Waktu Mengembalikan waktu baru setelah ditambah m menit
totalMenit Waktu w int Mengembalikan jumlah seluruh menit

Tips memilih tipe kembalian:

  • Kalau operasi menghitung dan menghasilkan satu angka, pakai tipe angka (int, double).
  • Kalau operasi menghasilkan data yang terdiri dari beberapa anggota, kembalikan struct-nya.
  • Kalau operasi hanya menampilkan sesuatu dan tidak menghasilkan nilai, pakai void.

Langkah merancang ADT baru, misalnya ADT Buku atau Lingkaran:

  1. Tentukan nama ADT (satu kata, diawali huruf besar).
  2. Tulis daftar data yang perlu disimpan, lalu tentukan tipe setiap data.
  3. Tulis daftar operasi yang diperlukan, dan untuk tiap operasi tentukan parameter dan tipe kembaliannya.
  4. Baru tulis kodenya.

10. Rangkuman

  • struct menggabungkan beberapa data menjadi satu tipe baru. Jangan lupa ; setelah }.
  • Menulis struct hanya membuat rancangan tipe. Variabelnya dibuat terpisah, misalnya Waktu w1;.
  • Anggota diakses dengan operator titik: w1.jam.
  • Nilai awal dapat diberikan dengan { ... } sesuai urutan anggota.
  • Menyalin struct (q = p) membuat salinan terpisah.
  • struct dapat menjadi parameter (yang diterima adalah salinan) dan nilai kembalian fungsi.
  • ADT = data + operasi. Di C++, data ditulis dengan struct dan operasinya ditulis sebagai fungsi atau prosedur.

11. Cek Pemahaman

Soal 1. Perhatikan kode berikut. Apa yang dicetak?

struct Kotak {
    int sisi;
    string warna;
};

int main() {
    Kotak k1 = {4, "merah"};
    Kotak k2 = k1;
    k2.sisi = 9;
    cout << k1.sisi << " " << k2.sisi << " " << k2.warna;
    return 0;
}
Lihat jawaban Soal 1

Keluarannya 4 9 merah.

k2 adalah salinan k1, sehingga k2.warna juga "merah". Setelah itu hanya k2.sisi yang diubah menjadi 9, sedangkan k1.sisi tetap 4.
