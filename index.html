Struct untuk Struktur Data Abstrak (ADT) dalam C++ — Penjelasan untuk Siswa SMA

🤔 Apa Itu struct?

Bayangkan kamu punya kartu pelajar. Kartu itu punya banyak informasi:

  • Nama
  • Kelas
  • NIS
  • Alamat

Daripada menyimpan 4 variabel terpisah, kamu bisa menggabungkannya menjadi satu "wadah" bernama kartu pelajar. Nah, struct di C++ itu persis seperti itu — wadah untuk menggabungkan beberapa data menjadi satu kesatuan.

struct = cara membuat "tipe data baru" yang berisi beberapa data lain di dalamnya.

📦 Analogi Sederhana

Tanpa struct (Berantakan)

string namaSiswa1 = "Budi";
int    kelasSiswa1 = 10;
string nisSiswa1  = "12345";

string namaSiswa2 = "Ani";
int    kelasSiswa2 = 11;
string nisSiswa2  = "67890";

Bayangkan kalau ada 100 siswa — 100 variabel nama, 100 kelas, 100 NIS! 😵

Dengan struct (Rapi)

struct Siswa {
    string nama;
    int    kelas;
    string nis;
};

Sekarang satu siswa = satu Siswa. Jauh lebih rapi! ✨

🧱 Cara Membuat struct

Bentuk Dasar

struct NamaStruct {
    tipe_data1 nama_field1;
    tipe_data2 nama_field2;
    // ...
};

Contoh Sederhana

struct Titik {
    int x;
    int y;
};

Ini membuat tipe data baru bernama Titik yang punya dua bagian: x dan y.

Cara Menggunakannya

int main() {
    Titik t1;        // buat variabel bertipe Titik
    t1.x = 5;        // isi bagian x
    t1.y = 10;       // isi bagian y

    cout << "Titik: (" << t1.x << ", " << t1.y << ")\n";
    // Output: Titik: (5, 10)
}

Perhatikan: kita pakai titik (.) untuk mengakses bagian dalamnya — disebut member access operator.

🔗 Hubungan struct dengan ADT

Ingat ADT?

ADT = data + operasi, dengan detail implementasi disembunyikan.

struct adalah salah satu cara membuat ADT di C++. Karena struct bisa berisi:

  1. Data (variabel)
  2. Operasi (fungsi/method)

Maka struct bisa menjadi wadah lengkap untuk sebuah ADT!

┌─────────────────────────────────┐
│         struct sebagai ADT      │
│                                 │
│  ┌───────────────────────────┐  │
│  │  DATA (variabel)          │  │
│  │  - arr, top, capacity     │  │
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │  OPERASI (fungsi)         │  │
│  │  - push(), pop(), peek()  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘

🆚 struct vs class di C++

Ini penting banget untuk dipahami!

Aspek struct class
Akses default public (terbuka) private (tertutup)
Bisa berisi fungsi? ✅ Bisa ✅ Bisa
Bisa punya constructor? ✅ Bisa ✅ Bisa
Bisa inheritance? ✅ Bisa ✅ Bisa
Biasanya dipakai untuk Data sederhana ADT kompleks

⚠️ Mitos yang salah: "struct tidak bisa punya fungsi." SALAH! Di C++ modern, struct bisa punya fungsi, constructor, bahkan inheritance — sama seperti class.

Perbedaan Satu-satunya

struct A {
    int x;   // ← default PUBLIC
};

class B {
    int x;   // ← default PRIVATE
};

Itu satu-satunya perbedaan mendasar!

💻 Contoh ADT Stack dengan struct

Versi 1: struct dengan Data Saja (Sederhana)

struct Stack {
    int arr[100];
    int top = -1;
};

int main() {
    Stack s;
    s.arr[++s.top] = 10;   // push manual
    s.arr[++s.top] = 20;

    cout << s.arr[s.top--];  // pop manual → 20
}

⚠️ Masalah: Karena semua public, pengguna bisa mengubah top atau arr sesuka hati → tidak aman!

Versi 2: struct dengan Fungsi (Lebih Baik)

struct Stack {
    int arr[100];
    int top = -1;

    // Operasi ADT
    void push(int x) {
        arr[++top] = x;
    }

    int pop() {
        return arr[top--];
    }

    int peek() {
        return arr[top];
    }

    bool isEmpty() {
        return top == -1;
    }
};

int main() {
    Stack s;
    s.push(10);
    s.push(20);
    s.push(30);

    cout << s.pop();   // 30
    cout << s.pop();   // 20
}

Lebih rapi! Tapi masih ada masalah — karena struct default public, pengguna masih bisa langsung mengakses s.arr atau s.top.

Versi 3: struct dengan private (ADT Sejati)

struct Stack {
private:                      // ← sembunyikan data
    int arr[100];
    int top = -1;

public:                       // ← buka operasi
    void push(int x) {
        arr[++top] = x;
    }

    int pop() {
        return arr[top--];
    }

    int peek() {
        return arr[top];
    }

    bool isEmpty() {
        return top == -1;
    }
};

int main() {
    Stack s;
    s.push(10);
    s.push(20);

    // s.arr[0] = 999;   ❌ ERROR! Tidak bisa akses
    // s.top = 50;       ❌ ERROR! Tidak bisa akses

    cout << s.pop();     // ✅ Bisa, lewat operasi resmi
}

Sekarang struct ini menjadi ADT sejati — data tersembunyi, operasi terbuka! 🎉

🍔 Contoh ADT Queue dengan struct

struct Queue {
private:
    int arr[100];
    int depan = -1;
    int belakang = -1;

public:
    void enqueue(int x) {
        if (depan == -1) depan = 0;
        arr[++belakang] = x;
    }

    int dequeue() {
        if (depan == -1 || depan > belakang) {
            cout << "Queue kosong!\n";
            return -1;
        }
        return arr[depan++];
    }

    bool isEmpty() {
        return depan == -1 || depan > belakang;
    }
};

int main() {
    Queue q;
    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);

    cout << q.dequeue();   // 10 (FIFO)
    cout << q.dequeue();   // 20
}

📚 Contoh Lain: struct untuk Data Siswa

Untuk data yang sederhana (tanpa logika rumit), struct paling cocok dipakai.

struct Siswa {
    string nama;
    int    kelas;
    string nis;

    void tampilkan() {
        cout << "Nama  : " << nama  << endl;
        cout << "Kelas : " << kelas << endl;
        cout << "NIS   : " << nis   << endl;
    }
};

int main() {
    Siswa s1;
    s1.nama  = "Budi";
    s1.kelas = 10;
    s1.nis   = "12345";

    s1.tampilkan();
}

Output:

Nama  : Budi
Kelas : 10
NIS   : 12345

🏗️ Kapan Pakai struct vs class?

Gunakan struct ketika:

  • Datanya sederhana (tanpa logika rumit)
  • Ingin semua terbuka (public)
  • Membuat "kumpulan data" seperti koordinat, tanggal, data siswa
  • Ingin kode singkat

Gunakan class ketika:

  • Membuat ADT kompleks (Stack, Queue, Tree)
  • Ingin data tersembunyi (private)
  • Butuh enkapsulasi yang kuat
  • Ada logika rumit di dalamnya

Panduan Sederhana

Data sederhana (koordinat, data siswa)?  → struct
ADT kompleks (Stack, Queue, Tree)?       → class
Tidak yakin?                              → class (lebih aman)

🎨 Perbandingan Visual

struct (data sederhana)

struct Titik {
    int x;
    int y;
};
// Cukup! Semua publik, tidak perlu sembunyikan apa-apa

class (ADT kompleks)

class Stack {
private:
    int arr[100];     // sembunyikan implementasi
    int top;
public:
    void push(int x); // buka operasi
    int pop();
};

🔄 Bisakah struct Menjadi ADT?

BISA! Seperti contoh Versi 3 tadi:

struct Stack {
private:           // ← trik: pakai private juga di struct
    int arr[100];
    int top = -1;

public:
    void push(int x) { arr[++top] = x; }
    int pop()        { return arr[top--]; }
};

Secara teknis, struct dan class hampir identik. Bedanya cuma default akses (public vs private).

Namun, konvensi komunitas C++ menyarankan:

Kebutuhan Rekomendasi
Data sederhana struct
ADT kompleks class

Poin Penjelasan

Bedanya dengan class? Default akses: struct = public, class = private

🎯 Kesimpulan

💡 struct di C++ adalah "wadah serbaguna" untuk menggabungkan data (dan fungsi) menjadi satu kesatuan. Bisa dipakai untuk data sederhana (seperti koordinat titik atau data siswa) maupun untuk membuat ADT (dengan menambahkan private:). Perbedaan utamanya dengan class hanya pada default akses — struct = public, class = private. Tapi secara konvensi, struct lebih cocok untuk data sederhana, sedangkan class untuk ADT kompleks seperti Stack, Queue, dan Tree. 🚀

│              STRUCT                    │
│                                        │
│  Data sederhana  → Struct (public)     │
│  ADT kompleks    → Class (private)     │
│                                        │
│  Keduanya bisa berisi data + fungsi!   │
└────────────────────────────────────────┘
