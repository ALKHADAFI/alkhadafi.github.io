Identitas Siswa

Ingat Kembali: Apa itu ADT?

Struktur data abstrak (ADT) terdiri dari data yang disimpan dan operasi yang dapat dilakukan pada data. Dalam C++, struct dapat digunakan untuk mengelompokkan data, sedangkan fungsi atau prosedur menyediakan operasinya. 

struct Siswa {
    string nama;
    int nilai;
};

void tampilkan(Siswa s) {
    cout << s.nama << " : " << s.nilai << endl;
}

Anggota struct diakses dengan operator titik, misalnya s.nama. Anggota struct bersifat public secara default.

Bagian B · Tebak keluaran · Skor 30

Telusuri isi struct

B1

Tuliskan keluaran program berikut.

struct Titik {
    int x;
    int y;
};

Titik a;
a.x = 2;
a.y = 5;

Titik b = a;
b.x = 10;

cout << a.x << " " << b.x << " " << b.y;
B2

Tuliskan keluaran program berikut.

struct Pecahan {
    int pembilang;
    int penyebut;
};

Pecahan kali(Pecahan p, Pecahan q) {
    Pecahan hasil;
    hasil.pembilang = p.pembilang * q.pembilang;
    hasil.penyebut = p.penyebut * q.penyebut;
    return hasil;
}

Pecahan a = {1, 2};
Pecahan b = {3, 4};
Pecahan c = kali(a, b);
cout << c.pembilang << "/" << c.penyebut;
